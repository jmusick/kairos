# Arcane raid review: 12.1.5 (70688), Oct. 30, 2026

The first full raid log supports continuing work on the addon, but does not
establish the 90% live-agreement target. The strongest remaining lead is
Prismatic Bolt selection and its competing priorities. Cooldown-toggle history
is missing, so suppressed Surge prompts cannot be diagnosed as a bug from this
capture alone.

## What the larger sample establishes

### Later live recommendations outperform AC, with Bolt the weakest category

At 260 on-GCD decision points across the seven Sszorak attempts, the displayed
spell agrees with the reconstructed APL on **219/260 (84%)**, against
**135/260 (52%)** for Assisted Combat. One displayed decision uses AC fallback.
The own-APL-only score is 219/259 (85%); that denominator excludes fallback.
Recorder alignment matches 312/321 cast successes, with offset -446942.473 s.

| Reference spell | Decisions | Display agrees | AC agrees |
|---|---:|---:|---:|
| Barrage, all clauses | 73 | 69 (95%) | 44 (60%) |
| Missiles | 68 | 62 (91%) | 24 (35%) |
| Prismatic Bolt, both rules | 47 | 25 (53%) | 8 (17%) |
| Blast | 59 | 53 (90%) | 54 (92%) |
| Surge | 7 | 5 (71%) | 0 |
| Orb | 6 | 5 (83%) | 5 (83%) |

Of the 22 Bolt mismatches, the display chose Barrage 13 times, Missiles six,
Touch twice and Orb once. Estimating Cumulative Power alone changes only one
of those 47 reference Bolt decisions; estimating Salvo alone changes 13.
This does not establish the complete live cause, but it argues against treating
every missed Bolt as a Cumulative Power counter problem. Live projection,
availability, movement, competing Salvo rules and sampling order need to be
separated before changing a model.

#### Follow-up: Bolt glow detection versus recommendation disagreement

The 53% figure measures recommendation agreement, not the accuracy of the Bolt
proc signal. Inspecting recorder events with the same cast-order/time boundaries
as the scorer shows the latest recorded Bolt-glow event is **on at all 47
reference Bolt decisions, including all 22 mismatches**. This is evidence against
a general failure to observe the glow; it does not recover the exact API result
or complete projected state used by each prior display evaluation.

All six mismatches displaying Missiles have a latest recorded Salvo estimate of
11, while reconstructed true Salvo is 12–15. Missiles has higher priority than
both Bolt rules while Clearcasting is up and Salvo is below 12. For example, at
23:35:31.642 the reference has Salvo 14 and Cumulative Power 8; the latest live
stack events have Salvo 11 and Cumulative Power 8, with the Bolt glow on for
about 11 seconds. The display selects `sunfury:arcane_missiles`. This is a
concrete example of Salvo/priority disagreement despite an observed Bolt proc.

Six of the 22 mismatches have a Bolt glow-on event only 4–8 ms before the scored
decision. The prior displayed pick may precede the proc/refresh, so these need
frame/order inspection before being counted as missed usable prompts. Other
candidates include moving-state filtering, the eight-stack/Arcane Soul gate,
and lookahead clearing Bolt when an in-progress Bolt is already being consumed.
The current capture does not assign these causes to all Barrage/Orb mismatches.
The two Touch mismatches also compare an immediate off-GCD cue with a GCD-only
reference. Do not describe the aggregate as a 47% Bolt detection failure.

The local `bolt-detail.lua`/`bolt-detail.tsv` export preserves the stock scorer's
boundaries and adds the preceding glow, Salvo, Cumulative Power and queued-pick
events; `print-bolt.py` and `count-bolt.py` reproduce these counts.

The seven pulls range from 76% to 95% display agreement, with only 14–65
decisions each. Do not treat the best small pull as validation of the target.

### Cooldown uncertainty explains some discrepancies, not all

The user may have left the Cooldowns toggle off earlier in the raid. Both saved
profiles end with it enabled, but neither records toggle history. The normal
replay assumes cooldowns enabled. That makes its early 78% figure provisional,
and the absence of early Surge prompts is not evidence of a defect.

A local sensitivity experiment also evaluates each reconstructed state with
both tagged cooldowns held exactly as D15 specifies: Touch and Surge ready=false,
with remains=45 and 90 respectively. This changes the reference, not the
recorded display or the observed casts. It is hypothetical, not recovered history:

| Sample | Reference with CDs enabled | Reference with CDs held |
|---|---:|---:|
| Early retained decisions | 464/594 (78%) | 478/594 (80%) |
| Sszorak | 219/260 (84%) | 208/260 (80%) |

On Sszorak's 247 decisions where both toggle assumptions give the same reference
spell, the display agrees on 208 (84%), versus AC on 135 (55%). This is a
filtered diagnostic subset, not an overall score corrected for missing history.
Toggle state also affects Touch-related Barrage rules, so simply removing Surge
rows would not faithfully model cooldowns off.

### Salvo remains the dominant estimator limitation

The full raid/trash window, 21:26:39–23:48:00, has 2,151 replay decisions.
Holding every other input at reconstructed truth gives:

| Measurement | Result |
|---|---:|
| Both stack estimates choose the true-state spell | 1,941/2,151 (90%) |
| Salvo estimated alone chooses the true-state spell | 1,951/2,151 (91%) |
| Cumulative Power estimated alone chooses the true-state spell | 2,133/2,151 (99%) |
| Salvo on the correct side of 12 | 1,852/2,151 (86%) |
| Same boundary, true Salvo 6–18 | 393/678 (58%) |
| Salvo on the correct side of 9 | 2,068/2,151 (96%) |
| Correct answer for Salvo=25 | 2,114/2,151 (98%) |
| Truth inside estimated low/high bounds | 1,562/2,151 (73%) |

Mean absolute Salvo error is 1.76 stacks, maximum 25. A small average error hides
the difficult decision boundary: several nearby stacks can flip Missiles versus
Barrage. The low/high bounds also fail to contain truth in 27% of samples; they
must not be described as guaranteed bounds. These are replay-estimator results,
not the live display's score or a claim that all other live state is correct.
No gains were tuned on this validation log.

### The raid confirms Clearcasting's observable and the Overpowered blind spot

The spell watch covers 375.9 seconds of fight time across the later attempts.
There are 113 Clearcasting changes, 30 Overpowered Missiles changes and 14
Arcane Soul changes in the selected window.

- All 113 Clearcasting changes have a nearby Missiles-glow change; 113/116 glow
  changes have a nearby Clearcasting change. Time-weighted glow/state mapping
  is 100% in this watched sample.
- No watched field reliably tracks Overpowered Missiles. Spell override, icon
  and action slot stay constant; display/cast/action counts remain secret.
  The Missiles glow follows Clearcasting, not the empowered-channel proc.
- This confirms a limitation of the fields tested, not proof that every
  possible observable has been exhausted.

Surge/Soul timing also remains consistent with the existing model for typical
windows: across 41 Soul applications, median Surge-success-to-Soul delay is
17.403 s and median Soul duration is 4.005 s. Shorter outliers exist, so these
medians do not validate a fixed timer at every early buff removal.

### Raid restrictions persist beyond leaving combat

The latest probes show Arcane Charges, proc glows, AC and `IsPlayerMoving`
readable in raid. Mana, speed, haste, cooldown fields and tracked auras remain
secret. The after-combat probe still has Encounter/Map restrictions and secret
auras/cooldowns; leaving combat does not guarantee a safe truth refresh.
All 40 retained probes report zero counted aura-event handler errors. This
does not audit all Lua errors, frame time or CPU cost.

## Next work supported by this evidence

1. Record toggle state and transitions, with enough context to start scoring
   after ring rollover or reload. Missing history should produce an explicit
   unscored interval rather than an assumed setting.
2. Preserve per-pull/session summaries or another bounded record sufficient
   for a whole raid. The current ring cannot supply whole-night live agreement.
3. Capture the live state behind Bolt/Barrage/Missiles decisions, especially
   movement, evaluation boundary, actual channel timing and cooldown gates.
4. Investigate the Salvo threshold and interval misses without retuning gains
   on the same log used to claim validation.

These are follow-up priorities, not changes made by this review. The replay
still approximates enemy count, cooldowns and GCD; it does not score off-GCD
Touch cues or fully reproduce live movement, cast projection and Orb flight.
No DPS gain, queued-icon accuracy or performance conclusion follows from these
numbers, and they do not resolve the global fallback decision.
